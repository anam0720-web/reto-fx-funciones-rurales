🎯 Objetivo de aprendizaje

Interpretar, representar y evaluar funciones lineales, cuadráticas y exponenciales para modelar situaciones rurales, resolver problemas y justificar conclusiones con expresiones, tablas y gráficas.

📏 Estándar relacionado

Referente de pensamiento variacional (grados 10°–11°): analizar relaciones de cambio, representar situaciones con expresiones algebraicas, tablas y gráficas, y modelar fenómenos para resolver problemas.

Síntesis pedagógica del Estándar Básico de Competencias en Matemáticas del MEN; no es una cita textual.

📚 Referentes curriculares

DBA 7 · Referente principal

Resuelve problemas mediante el uso de las propiedades de las funciones y usa representaciones tabulares, gráficas y algebraicas para estudiar la variación, la tendencia numérica y las razones de cambio entre magnitudes.

EBC-1 · Conexión con funciones

Analizo las relaciones y propiedades entre las expresiones algebraicas y las gráficas de funciones polinómicas y racionales y de sus derivadas.

EBC-2 · Aplicación a magnitudes

Resuelvo y formulo problemas que involucren magnitudes cuyos valores medios se suelen definir indirectamente como razones entre valores de otras magnitudes, como velocidad media, aceleración y densidad medias.

EBC-3 · Representación geométrica

Reconozco y describo curvas y/o lugares geométricos.

DBA 2 · Apoyo conceptual

Utiliza las propiedades algebraicas de equivalencia y de orden de los números reales para comprender y crear estrategias que permitan compararlos y comparar subconjuntos de ellos (por ejemplo, intervalos).

DBA 3 · Aplicación a razones entre magnitudes

Resuelve problemas que involucran el significado de medidas de magnitudes relacionales (velocidad media, aceleración media) a partir de tablas, gráficas y expresiones algebraicas.

DBA 5 · Conexión geométrica

Explora y describe las propiedades de los lugares geométricos y de sus transformaciones a partir de diferentes representaciones.

¿Qué es una función?

Una función es una regla que asigna a cada entrada permitida x exactamente una salida f(x).

f(x) = 2,5x
Variable independiente (x)

Área sembrada, en m².

Variable dependiente f(x)

Estimación de mazorcas.

Dominio

Valores permitidos de x; aquí x ≥ 0, limitado al área disponible.

Rango

Salidas que produce la función para el dominio elegido.

📈 Modelando la realidad: tres historias del campo

Las funciones no se comportan igual. Compara los modelos y recuerda que sus resultados solo tienen sentido dentro del contexto y dominio indicado.

📏 Función lineal: los postes de la cerca

Doña Rosa necesita 3 postes por metro de cerca y 2 postes adicionales para las esquinas.

P(x)=3x+2

Para 15 metros: P(15)=3×15+2=47 postes.

🪣 Función cuadrática: modelo hipotético del tanque

Para estudiar la forma de una parábola, usamos el modelo hipotético h(t)=−t²+10t, donde t son horas y h(t) es un nivel relativo en centímetros.

h(t)=−t²+10t, para 0≤t≤10

El máximo ocurre en t=−b/(2a)=5 horas. h(5)=25 cm. El modelo baja después; no debe interpretarse como tanque real sin datos que justifiquen ese comportamiento.

🦠 Función exponencial: una plaga que se duplica

En un ejemplo simplificado, hay 5 insectos al inicio y la cantidad se duplica cada día.

N(d)=5×2ᵈ

En 3 días: N(3)=5×2³=40 insectos. Es un modelo de crecimiento simplificado, no una predicción agrícola garantizada.

DESARROLLO · MISIÓN 3

🧮 Resolviendo problemas para la vereda

👋 Sara, tu guía

¡Ya estás avanzando muy bien! 🚜 Ahora usaremos las funciones para analizar ganancias, caudal y temperatura en situaciones de la vereda.

💰 Problema 1: ¿cuándo hay ganancias?

Una panelería estima costos C(x)=500x+8.000 pesos e ingresos I(x)=1.200x, donde x es el número de panelas vendidas.

U(x)=I(x)−C(x)=700x−8.000

Equilibrio: 700x−8.000=0, así que x≈11,43. Como las panelas se cuentan en unidades enteras, se deben vender 12 panelas para tener utilidad positiva. Con 11 aún hay pérdida.

💧 Problema 2: caudal en un canal

Modelo aproximado: Q(d)=80−3d, donde d es distancia en metros y Q es caudal en litros por minuto.

Q(d)=80−3d

Para d=20: Q(20)=80−60=20 L/min. El dominio físico del modelo se limita a 0≤d≤26,67 m; un caudal negativo no tendría sentido aquí.

🏔️ Problema 3: altura y temperatura

Modelo ilustrativo: T(h)=22−0,006(h−500), donde h es la altura en metros sobre el nivel del mar. Para este ejemplo consideramos h≥500 m.

T(h)=22−0,006(h−500)

Si un cultivo requiere entre 18 °C y 24 °C, dentro de este modelo el intervalo aproximado es de 500 m a 1.167 m. Esto no sustituye datos climáticos locales ni recomendaciones agronómicas.

🚜 Actividad de ampliación: velocidad media

Un tractor recorre 18 kilómetros en 1,5 horas para transportar insumos. La velocidad media se calcula como distancia dividida entre tiempo: v = d/t. Esta actividad conecta el uso de funciones y tablas con el DBA 3 y el EBC-2.

v = distancia ÷ tiempo

Reflexiona: ¿por qué debemos comprobar que los datos, las unidades y el dominio tengan sentido antes de tomar decisiones reales?

🎮 Quiz de aplicación

Usando Q(d)=80−3d, ¿cuánto caudal estima el modelo a 20 m?
